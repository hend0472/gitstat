Metric definitions

How each number is calculated

Medians, ranks and percentiles compare each developer only with peers active in the same area (authors for authoring metrics, reviewers for review metrics, committers for commit metrics). These numbers describe how work flows, not how valuable it is: use them to start conversations, alongside context about scope, mentoring, design and on-call work that doesn't show up in git.
